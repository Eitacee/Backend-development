## 📋 Overview
This experiment implements a reactive client-side To-Do management system using modern **ECMAScript 6 (ES6+)** language features and DOM event handling.

## 💡 Core Concepts Implemented
- **ES6 Classes**: Encapsulated state and methods using `class Task` and `class TodoApp`.
- **Spread & Rest Operators (`...`)**: Immutable state manipulation.
- **Destructuring**: Clean extraction of task properties (`const { id, title, completed } = task`).
- **Event Delegation**: Efficient event handling on parent container elements.

## 📁 Files
- `index.html`: Web interface structure.
- `app.js`: ES6 JavaScript application logic.

## 📋 Overview
Experiment 15 introduces full-stack Python backend development using the **Django** web framework. It implements a baseline task management application adhering to Django's **MVT (Model-View-Template)** architectural pattern.

## 📁 Subdirectories
- `django_todo_app/`: Django project root containing settings, URL routing, models, and migrations.

## 🛠️ Technologies
- **Python 3**, **Django 5+**, **SQLite3**

## 🚀 How to Run
```bash
cd "Lab/Exp15/django_todo_app"
python manage.py migrate
python manage.py runserver
```
Visit `http://127.0.0.1:8000` in your browser.

## 📋 Overview
A clean Django task manager demonstrating:
1. **ORM Modeling**: `Task` model with title, description, completion status, and timestamps.
2. **Views & Routing**: Function-based views for listing, adding, toggling, and deleting tasks.
3. **Templates**: Clean HTML templates using Django Template Language (DTL).

## 🚀 How to Run
```bash
python manage.py migrate
python manage.py runserver
```

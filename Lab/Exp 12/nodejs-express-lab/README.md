## 📋 Overview
A modular Node.js Express application showcasing:
1. Dynamic page rendering with **EJS** templating.
2. Route parameter extraction (`req.params`) and query parameter parsing (`req.query`).
3. Calculation routes and conditional response formatting.

## 🛠️ Technologies
- **Node.js**, **Express.js**, **EJS**

## 🌐 Routes
- `GET /`: Home page rendered with dynamic context (`home.ejs`).
- `GET /users`: User directory view (`users.ejs`).
- `GET /profile/:username`: Dynamic profile renderer (`profile.ejs`).

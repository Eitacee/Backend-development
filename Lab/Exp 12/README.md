## 📋 Overview
Experiment 12 demonstrates building a server-side web application with **Express.js**, parameterized route handling, query string evaluation, and dynamic HTML rendering using the **EJS** templating engine.

## 📁 Directory Structure
- `nodejs-express-lab/`: Main application directory.
  - `app.js`: Express server setup, middleware, and route handlers.
  - `views/`: EJS template views (`home.ejs`, `profile.ejs`, `users.ejs`).
  - `package.json`: Project configuration and dependencies.

## 🚀 How to Run
```bash
cd "Lab/Exp 12/nodejs-express-lab"
npm install
node app.js
```
Open `http://localhost:3000` in your browser.

## 📋 Overview
This experiment demonstrates connecting an Express.js backend application to a **MongoDB** database using the **Mongoose** Object Data Modeling (ODM) library. It covers connection setup, defining schemas, models, and handling basic CRUD operations with JSON middleware.

## 🛠️ Technology Stack
- **Node.js** (Server-side JavaScript runtime)
- **Express.js** (Web application framework)
- **MongoDB** (NoSQL document database)
- **Mongoose** (Object Data Modeling ODM)

## 📁 Files
- `server.js`: Server setup, MongoDB connection string (`mongodb://127.0.0.1:27017/`), JSON body parser middleware, and REST routes.
- `package.json`: Project manifest and npm dependencies (`express`, `mongoose`).

## 🚀 How to Run
```bash
# 1. Navigate to directory
cd "Lab/Exp 13A"

# 2. Install dependencies
npm install

# 3. Ensure MongoDB is running locally on port 27017
# 4. Start the server
node server.js
```
The server will start listening on port 3000 (`http://localhost:3000`).

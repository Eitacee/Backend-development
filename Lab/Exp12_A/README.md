## 📋 Overview
Practical implementation of an Express.js backend with server-side rendering (SSR) using **EJS**. Demonstrates route dispatching, query string calculators, and modular view partials.

## 🛠️ Technologies
- **Node.js**, **Express.js**, **EJS**, **Nodemon**

## 📁 Key Files
- `app.js`: Application entrypoint defining REST endpoints and view engine configuration.
- `script.js` / `nodemon.js`: Helper and live-reload configuration scripts.
- `views/home.ejs`, `views/profile.ejs`, `views/users.ejs`: Server-side rendered views.
- `package.json`: Package dependencies.

## 🚀 How to Run
```bash
cd Lab/Exp12_A
npm install
node app.js
```

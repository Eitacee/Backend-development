## 📋 Overview
An advanced Django project showcasing modular multi-app design:
- `todo/`: Main task management application with custom CSS/JS assets.
- `tasks/`: Task categorization and workflow management.
- `student_api/`: External proxy endpoints and JSON utility helpers (`utils.py`).

## 🚀 How to Run
```bash
cd "Lab/Exp15B/django todo app"
python manage.py migrate
python manage.py runserver
```

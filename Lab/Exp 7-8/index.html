EXPERIMENT 07 & 08: ES6, DOM MANIPULATION, AND EVENT HANDLING

Course: Web Technologies / Backend Development Lab Target Standards: ECMAScript 2015+ & W3C DOM Level 3 SAP ID: 590014595

1. Objective

To understand and apply ES6 (ECMAScript 2015) features in JavaScript, learn DOM (Document Object Model) manipulation, and implement event handling to build interactive web pages. By the end of this experiment, students will be able to write modern, clean JavaScript, dynamically modify HTML/CSS through the DOM tree, and respond to asynchronous user interactions using event listeners.

2. Hardware and Software Requirements

Component Specification / Environment
Processor Intel Core i3 / AMD Ryzen 3 or higher
RAM Minimum 4 GB (8 GB recommended)
Operating System Windows 10/11, Linux, or macOS
Code Editor Visual Studio Code / Antigravity IDE
Web Browser Google Chrome 90+, Mozilla Firefox 88+, or Microsoft Edge (Chromium)
JavaScript Engine V8 Engine (built-in browser runtime / Node.js)

3. Theoretical Background

A. Key Innovations in ES6 (ECMAScript 2015)

ECMAScript 6 significantly matured JavaScript from a basic browser scripting language into a robust, object-oriented language for enterprise applications:

  • Block Scoping (let & const): Replaced function-scoped var, eliminating unintended hoisting side-effects and enforcing constant references.
  • Arrow Functions (() => {}): Shorter function syntax with lexical scoping for the this keyword (it inherits this from its defining scope).
  • Template Literals: Multi-line strings and expression interpolation via backticks (`Hello, ${name}`).
  • Destructuring Assignment: Clean syntax for unpacking values from arrays or object properties into distinct variables: const { id, title } = task;.
  • Spread & Rest Operators (...): Enables shallow cloning, array concatenation, and gathering dynamic arguments without the legacy arguments object.
  • Array Iteration Methods: Functional methods like map(), filter(), and reduce() that return new arrays rather than mutating existing data.
  • Classes & Modules: Formal syntax for constructors, methods, inheritance (extends), and encapsulation.

B. Document Object Model (DOM) Architecture

The DOM is a programming API for HTML documents representing the webpage structure as a tree of nodes (Document -> Root Element <html> -> <head> / <body> -> child nodes). Key manipulation methods include:

  • Targeting Nodes: document.querySelector(), document.querySelectorAll(), document.getElementById().
  • Mutating Content: node.textContent (secure plain text), node.innerHTML (parses markup).
  • Creating and Injecting: document.createElement('tagName'), followed by parent.appendChild(), parent.prepend(), or parent.append().
  • Modifying Styles & Classes: element.classList.add(), remove(), toggle(), and direct CSS custom properties.

C. Browser Event-Driven Architecture

User interactions fire asynchronous events in the browser. addEventListener(eventType, handlerFunction, options) registers listeners:

  • Event Propagation Phases: (1) Capturing phase (root down to target), (2) Target phase, and (3) Bubbling phase (target bubbling up to document root).
  • Preventing Defaults: e.preventDefault() stops default browser actions (such as form submits reloading the page).
  • Halting Propagation: e.stopPropagation() stops the event from propagating further up or down the DOM hierarchy.
  • Event Delegation Pattern: Leveraging event bubbling by placing a single event listener on a common ancestor to manage dynamic child elements, vastly improving memory performance.

4. Viva Voce Questions & Model Answers

Q1: What are the differences between var, let, and const?
var is function-scoped and hoisted with an initial value of undefined, allowing accidental redeclaration. let and const are block-scoped and reside in a "Temporal Dead Zone" (TDZ) from the start of the block until declared. const cannot be reassigned after declaration.
Q2: How do arrow functions handle the this keyword differently from traditional functions?
Traditional functions bind this dynamically based on how the function was invoked (method call, standalone function, constructor, or call/apply). Arrow functions have lexical this—they do not bind their own this, but instead inherit it directly from the parent lexical scope.
Q3: What is the difference between textContent, innerText, and innerHTML?
textContent returns the raw text content of all elements including hidden scripts and styles without triggering a browser reflow. innerText is style-aware and only returns human-readable text that is visible on the screen, triggering reflow. innerHTML gets or sets the HTML markup inside an element, parsing tags but opening potential XSS security risks if untrusted inputs are used.
Q4: Explain Event Bubbling vs Event Capturing with real-world examples.
In Event Capturing (Trickling), the event starts at the highest ancestor (window/document) and trickles down to the target element. In Event Bubbling, the event fires on the target element first and bubbles upward through parent nodes until reaching the document. By default, addEventListener listens in the bubbling phase unless { capture: true } is specified.
Q5: What is Event Delegation and why is it recommended for dynamic web pages?
Event Delegation is a technique where instead of adding individual event listeners to hundreds of child elements (e.g., list items), you attach a single event listener to their parent container. When any child is clicked, the event bubbles up to the parent, where event.target identifies the clicked element. This dramatically reduces memory overhead and automatically handles dynamically created elements without needing to bind new listeners.
Q6: What is the difference between event.target and event.currentTarget?
event.target refers to the specific element that actually triggered the event (the innermost element clicked). event.currentTarget refers to the element to which the event listener is currently attached.

5. Learning Outcomes & Conclusion

Through this experiment, we successfully investigated and applied modern ECMAScript 2015+ syntax rules (variables, arrow functions, destructuring, template literals, and array methods). We demonstrated programmatic manipulation of the Document Object Model (DOM) by dynamically inserting, mutating, styling, and removing HTML nodes. Finally, we mastered browser event handling, including bubbling, capturing, cancellation (preventDefault/stopPropagation), and event delegation. The interactive Capstone application validates how these three foundational pillars combine to construct performant, responsive web interfaces.

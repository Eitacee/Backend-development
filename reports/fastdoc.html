1. Overview & Objective

The fastdoc task implements a lightweight, RESTful Student Management API engineered with Node.js and Express. It serves as both a local development project and a practical exercise in custom container creation utilizing the manual docker commit workflow instead of conventional Dockerfile builds.

  • Implement RESTful CRUD operations (Create, Read, Delete) for student records using an in-memory data store.
  • Configure development workflow with nodemon for hot-reloading and production startup scripts.
  • Demonstrate containerization concepts by manually spawning interactive containers, provisioning dependencies, and snapshotting images with docker commit.

4. REST API Endpoint Specifications

The Express application binds to port 3000 and exposes the following endpoints:

  • GET /: Welcome message, version info, and dictionary of available endpoints.
  • GET /students: Retrieve all active student records in JSON format.
  • GET /students/:id: Retrieve a single student matching the unique ID parameter.
  • POST /students: Ingest a new student JSON payload (name, course, age).
  • DELETE /students/:id: Remove a student record matching the specified ID.

5. Docker Manual Containerization Workflow (`docker commit`)

Instead of relying on an automated Dockerfile build, this practical demonstrates stateful container snapshotting:

# 1. Run an interactive base container
docker run -it -d --name fastdoc-builder -p 3000:3000 -w /app node:18-alpine sh

# 2. Copy source code into the running container
docker cp . fastdoc-builder:/app

# 3. Install production dependencies inside the container
docker exec -it fastdoc-builder npm install --production

# 4. Commit the container snapshot with default working directory and startup command
docker commit -c "WORKDIR /app" -c "CMD node app.js" fastdoc-builder fastdoc-image:latest

# 5. Stop and clean up builder container
docker stop fastdoc-builder && docker rm fastdoc-builder

# 6. Run the new production container from committed image
docker run -d --name fastdoc-app -p 3000:3000 fastdoc-image:latest

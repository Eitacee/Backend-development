4. Implementation & Code Breakdown

Demonstrates querying semi-structured documents within relational tables:

-- Creating a table with mixed relational columns and JSONB documents
CREATE TABLE student_profiles (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    metadata JSONB
);

-- Indexing JSONB document keys using GIN
CREATE INDEX idx_student_metadata ON student_profiles USING GIN (metadata);

-- Querying using JSON containment operator (@>)
SELECT * FROM student_profiles WHERE metadata @> '{"branch": "CSE"}';

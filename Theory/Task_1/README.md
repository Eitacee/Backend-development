## 📋 Overview
Implements dynamic server-side rendering (SSR) using **Node.js**, **Express.js**, and the **EJS** view engine. Demonstrates rendering dynamic collections into HTML tables and lists.

## 📁 Key Files
- `server.js`: Express server and routing definitions.
- `views/home.ejs`: Welcome landing page view.
- `views/students.ejs`: Dynamic student directory table view.
- `package.json`: Project manifest and scripts.

## 🚀 How to Run
```bash
cd Theory/Task_1
npm install
node server.js
```

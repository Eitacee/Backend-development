## 📋 Overview
Comprehensive demonstration of state tracking and persistence in Express.js backends using HTTP Cookies and server-side Sessions.

## 📁 Modules
- `cookies/app.js`: Setting, reading, and clearing signed/unsigned cookies using `cookie-parser`.
- `session/app.js`: Session store configuration, session ID generation, and session state persistence using `express-session`.

## 🚀 How to Run
```bash
cd Theory/Lec_06
npm install

# Run Cookies Demo:
node cookies/app.js

# Or Run Session Demo:
node session/app.js
```

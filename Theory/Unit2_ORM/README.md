## 📋 Overview
Demonstrates Python Object Relational Mapping using **SQLAlchemy** and SQLite. Implements relational models with bidirectional foreign key relationships using `relationship(..., back_populates=...)`.

## 📁 Files
- `main.py`: SQLAlchemy engine setup, DeclarativeBase models, and session queries.
- `Pipfile` / `Pipfile.lock`: Dependency specification for Pipenv.
- `students.db`: SQLite database file.

## 🚀 How to Run
```bash
cd Theory/Unit2_ORM
pip install sqlalchemy
python main.py
```

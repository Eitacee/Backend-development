## 📋 Overview
Demonstrates NoSQL Object Data Modeling for MongoDB using **Mongoose**. Covers schema validation, required fields, enum constraints, string trimming, and lowercase normalization.

## 📁 Files
- `app.js`: Express server with Mongoose schema definitions and validation tests.
- `package.json`: Project dependencies.

## 🚀 How to Run
```bash
cd Theory/Unit2_ODM
npm install
node app.js
```

## 📋 Overview
Demonstrates client-side data persistence without a database backend using the browser's native **`localStorage`** API.

## 📁 Files
- `index.html`: Responsive task management UI.
- `script.js`: DOM manipulation, JSON serialization (`JSON.stringify`/`JSON.parse`), and persistence logic.
- `style.css`: Clean modern stylesheet.
